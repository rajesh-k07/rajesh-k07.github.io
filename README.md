# Rajesh Kumawat — Personal Portfolio Site

This repository holds the source code for my personal portfolio website, hosted with GitHub Pages.

🔗 **Live site:** [rajesh-k07.github.io](https://rajesh-k07.github.io)

## About

A single-page site covering my background, focus areas, and current work. It includes:

- **About** — background, education, and areas of focus
- **Work** — links to project repositories
- **Contact** — how to reach me

## Built with

- HTML / CSS (no framework — hand-built, single-page)
- Hosted via [GitHub Pages](https://pages.github.com/)

## Structure

This repo contains only the site itself (`index.html`). Project code, notebooks, and
write-ups live in their own separate repositories, linked from the site.
